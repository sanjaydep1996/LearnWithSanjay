# Episode 01: Architecting a 3D AI Citadel (DevCity)

In this episode, we build a local-first developer companion and 3D Citadel that visualizes Claude Code / Antigravity spend and architecture without sending any code or prompts to the cloud.

## Key Architecture Concepts
1. **Python stdlib Collector**: Scanning local session JSONLs and calculating token / prompt caching economics.
2. **Zero-Build Three.js Visualizer**: Procedural building generation, glow shaders, and campus switching.
3. **Model Context Protocol (MCP)**: Exposing read-only tools over stdio to Cursor and Claude Code.
