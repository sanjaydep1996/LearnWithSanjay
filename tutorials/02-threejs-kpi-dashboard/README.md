# Episode 02: Zero-Build 3D Live KPI & PropTech Dashboard

In this episode, we build a config-driven 3D KPI visualizer using pure HTML and Three.js from a CDN.

## Key Concepts
1. **Config-Driven Architecture**: All metrics and building shapes declared in `config.js`.
2. **Polling & Interpolation**: Smoothly counting numbers up to new values between polls.
3. **PropTech & Digital Twin Use Cases**: Visualizing HVAC efficiency, chiller status, and occupancy for smart buildings.

See full project: [github.com/sanjaydep1996/3d-live-dashboard-template](https://github.com/sanjaydep1996/3d-live-dashboard-template)
