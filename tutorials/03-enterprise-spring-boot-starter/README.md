# Episode 03: Enterprise Spring Boot 3 & Java 21 Production Core

In this episode, we explore enterprise-scale architecture patterns in Java 21 and Spring Boot 3.3.

## Architectural Patterns Covered
1. **Idempotency & Distributed Transactions**: Idempotency keys and transactional outbox pattern with Apache Kafka.
2. **Resilience & Circuit Breaking**: Implementing Resilience4j rate limiting and fallbacks.
3. **Integration Testing**: Using Testcontainers to spin up real PostgreSQL and Kafka instances in CI.
